# Проверка воспроизводимости с нуля

**Дата:** 09.10.2026. **Что проверялось:** можно ли получить результаты проекта в чистой копии репозитория,
без локальных данных и кэша, одной командой.

## Как

1. Свежий клон опубликованного репозитория в пустую папку.
2. `python scripts/run.py` — от скачивания исходных данных до последнего шага.
3. Сравнение получившихся файлов `outputs/` с опубликованными по SHA-256 (`scripts/s19_checksums.py`,
   переводы строк CRLF/LF нормализуются).

Окружение: Windows 11, Python 3.13.1, numpy 2.3.5, pandas 3.0.2, scikit-learn 1.8.0, scipy 1.17.1,
igraph 1.0.0, leidenalg 0.12.0, pyarrow 23.0.1, torch 2.11.0 (CPU).

## Результат

| Шаг | Время | Итог |
|---|---|---|
| `s01_download` — скачивание всех исходных файлов с нуля | 52 с | 9 из 9 файлов прошли проверку SHA-256 |
| `s02_panel` — панель МО | 15 с | выполнен без ошибок |
| `s03_edges` — восемь правил ребра | 55 с | `outputs/edges/summary.csv`, `jaccard.csv` совпали байт в байт |
| `s04_external_code` — код CANUS на закреплённом коммите | 30 с | скачан |
| `s05_choose_k` — выбор числа типов | 384 с | `outputs/choose_k/summary.csv` совпал по всем значениям (см. ниже) |
| `s06_methods` и далее | — | **не завершены**: прогон остановлен из-за нехватки оперативной памяти на машине, не из-за ошибки кода |

## Что нашла проверка и что исправлено

В `choose_k/summary.csv` свежий прогон дал лишнюю колонку `MQ_basic`: индекс BasicMQ был добавлен в общую функцию
сетевых индексов после того, как опубликованные таблицы были посчитаны. Все остальные значения совпали точно
(максимальное расхождение 0,0). Исправление: BasicMQ теперь считается только по запросу (`graph_icvi(..., basic=True)`)
в проверке рейтинга `s13_checks.py`, поэтому основные таблицы снова в точности соответствуют коду. Повторно сверено:
индексы KEFRiN-c, пересчитанные текущим кодом, совпадают с опубликованной `outputs/method_comparison/icvi_raw.csv`.

## Ограничения

- Шаги с `s06_methods` (сравнение 13 методов, около 30 минут и нескольких ГБ памяти) в этой проверке с нуля не
  повторены. Их воспроизводимость проверяется командой `python scripts/s19_checksums.py --check` после полного прогона.
- Проверка шла на одной машине под Windows; Linux и macOS не проверялись.
